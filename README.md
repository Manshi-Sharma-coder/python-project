# 🧙‍♂️ Harry Potter Quiz Game (Terminal Edition)

A fun command-line quiz game based on the magical world of **Harry Potter**!
Test your knowledge and see how well you know the wizarding world.

---

## ✨ Features

* 🎨 Colorful terminal output
* 🔀 Randomized question order
* 📊 Score calculation with percentage
* 🏆 Performance feedback (Excellent / Good / Try Again)
* 🔁 Play again option
* 🖋 ASCII art title using `pyfiglet`

---

## 📦 Requirements

Make sure you have Python 3 installed.

Install the required libraries:

```bash
pip install colorama pyfiglet
```

---

## 🚀 How to Run

1. Save the script as `quiz.py`
2. Open your terminal
3. Run:

```bash
python quiz.py
```

---

## 🎮 How to Play

* The game will display 5 multiple-choice questions.
* Type **a**, **b**, **c**, or **d** to answer.
* Your score will be shown at the end.
* Choose whether you want to play again.

---

## 📚 Questions Included

The quiz includes questions about:

* Harry's Hogwarts house
* The author of the series
* His Quidditch position
* His pet owl
* Famous spells

---

## 🏆 Scoring System

* **80% or more** → 🎊 Excellent Work!
